# 旅迹真机备份测试

`.triptrailbackup` 可用于真机导入测试。备份可能包含旅行数据和媒体原件，因此此类文件不会提交到代码仓库。

建议使用仅含测试数据的本地备份，覆盖不同状态的行程、足迹、地点类别、交通方式、预约、费用和媒体，以验证完整恢复流程。

真机测试步骤：

1. 将本地测试备份通过隔空投送、微信文件或“文件”App 发送到 iPhone。
2. 在旅迹的“我的 → 完整备份与换机 → 从备份恢复”中选择该文件。
3. 检查预览数量后确认恢复。恢复会替换旅迹当前本地数据，并把媒体写入真机相簿、重建本机索引。

恢复是覆盖操作，建议只在测试设备或已另行备份数据的设备上执行。
